# Day 3 Assignment – Data Architecture with Databricks

## Overview
This project explores three important modern data architecture concepts: Data Warehouse, Data Lake, and Data Lakehouse.

It explains how Databricks supports modern data engineering through Delta Lake, Unity Catalog, and Medallion Architecture.

## Topics Covered
- Data Warehouse
- Data Lake
- Data Lakehouse
- Comparison of the three architectures
- Databricks Lakehouse Platform
- Unity Catalog
- Managed and External Tables
- Tables vs Volumes
- Medallion Architecture

## Medallion Architecture

The Medallion Architecture organizes data into three logical layers:

1. **Bronze:** Raw data.
2. **Silver:** Cleaned and validated data.
3. **Gold:** Business-ready data.
